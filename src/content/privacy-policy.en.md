## 3. Automatically collected data

When you use the Application, certain technical data is automatically collected, including your IP address, device model, operating system and version, device identifiers, and session identifiers. This data is personal data within the meaning of Art. 4(1) GDPR. It is used exclusively to:

- identify and monitor software errors and crashes;
- measure API call performance and page/screen load times;
- debug issues and improve the stability and performance of the Application.

We do not use this data to identify you as an individual, to create user profiles, or for advertising purposes. We limit the data collected to what is necessary for these purposes.
